# Scorched Guns 2[1]

An unofficial port, Scorched Guns **21** brings [Scorched Guns 2](https://github.com/ribs498/Scorched-Guns-1.20.1) to **NeoForge 1.21.1**!


Changes in this port:
  - The cog chambers were not ported, because of trial chambers, in the future I'll add a special room for the boss fight and expand the trial chambers with Scorched Guns content.
  - Bayonet behaviour was slightly changed, might feel better to use now.
  - Framework is no longer a dependency
  - Some smaller bugs from the original mod was fixed.
  - Added compatibiltiy for Sable ( bullets now interact with sable objects)
  - Added ability for shotguns to break blocks (can be configured if more than 10 pellets strike one they break, similar to heavier guns)
  - Added an experimental progression system (can be turned on, it is off by default): that tries to imitate progression similar to earlier versions, by having to find blueprints, and  then research the guns from them using a new block.
  
### Everything else behaves the same, if dont report it either here, or on my [DISCORD](https://discord.gg/yCRacrxczE) along with other bugs/incompatibilities you may find!

## Requirements

- **Minecraft** `1.21.1+`
- **NeoForge** `21.1+`
- [Curios API](https://modrinth.com/mod/curios) `9.5.1+` 
- [GeckoLib](https://modrinth.com/mod/geckolib) `4.9.3+`
